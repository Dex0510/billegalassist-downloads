# billegalassist early-access downloads

Binary downloads and pilot documentation only. The application source repository
remains private.

The Windows x64 pilot is **unsigned**, connects to **isolated staging services**,
and has not completed native Windows acceptance. Read the release notes and pilot
guide before downloading. Accounts and recovery are coordinator-assisted; real
payments and customer email delivery are unavailable.

Use sample data first. Installation and workflow feedback is welcome through
https://billegalassist-staging.vercel.app/feedback. Never post credentials,
recovery keys, confidential documents or customer information.

This repository's prerelease assets are separate from the application's signed
production release/update channel. Third-party notices are supplied with the
installer; publishing this download repository does not publish or relicense the
private application source.
